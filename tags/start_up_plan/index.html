    有团队了？接下来呢？

    我显然对搞钱过于着急了，不是随便一个人订阅各种 AI 工具纯靠动嘴就能做出一个能挣钱的创业项目的。我需要先学些东西，至少要能看懂 AI 写的代码，能构建起一个 Agent 的框架，才能不烧一堆 token 做出没什么意义的屎山代码。 我的伙伴数学底子很好，也有学 python，但我似乎高估了他的程度。我们都还有很长的路要走，但时间有限。目前的目标是——在六月前搞出有脸写在简历上的 Agent 项目。 那么，我们在三月就应当学完所有的基础知识，包括Python(PyTorch)和LLM、Agent的基础，目标是自己糊出一个agent来。 翻翻日历，我们有四周时间，可以做一个大概完不成但是做着挺好玩的计划： 第一周：Python 学到够用 我有 Java 经验（算得上的话），伙伴 Python 在学面向对象，我们可以算是同一起跑线。Python 这玩意应该没多难，我只需要尽快熟悉语法和特性上与 Java 的异同就可以掌握，再学些 pytorch 的基础部分，能读懂代码就好。要鼓励伙伴快点学，多去读文档，做点小玩具，在实践中增强理解加速学习。 我的具体规划 周二学列表/dict 周三学函数式写法 周四学类与面向对象特性 周五学装饰器、async/await 周末选一个较综合的 Java 项目用 python 重写 >这规划可能是AI胡写的，感觉完全要不了这么慢，今天周三，我学完了面向对象特性，我昨天甚至去打LOL了 >今天周四，后面的有点抽象了，我在学异步 >还在周四，我感觉差不多了，剩下的知识可以边用边补了 >我想学一下现在的AI编程是个什么流程，尝试用Codex或Qoder做一个python的21点游戏。不能忘了我学这不是为了自己做，能看懂AI做就好了 第二周：学习 LLM+Agent 基础 说实话，我们完全不知道 Agent 到底是啥，该怎么学，根据之前听某个网红的说法，我打算边读姚顺雨关于 Agent 的论文，边上UC Berkeley 的 CS294-196，那就是一天 2-3 个 lecture，抽空再把论文一读。 别忘了参考 ChatGPT 给的指导： 重点学： Prompt engineering Chain-of-thought ReAct Tool use Function calling JSON schema 输出控制 要亲手做： 一个带工具的 agent: 计算器/网络搜索/文件读写 一个多步任务 agent: 任务拆分 中间状态保存 ...
