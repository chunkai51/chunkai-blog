    追了一圈各种小龙虾XXClaw，答案却藏在ChatGPT侧边栏：OpenAI Codex终于做好了“AI用电脑”这件事

    过去几个月，我像追连续剧一样追各种“xxClaw”“小龙虾”。 OpenClaw、CoPaw、QClaw、QoderWork、WorkBuddy……名字一个比一个像能从桌面角落里爬出来帮我打工。最开始体验OpenClaw时最兴奋，那是过年那会儿，我把 OpenClaw 接上钉钉，然后用手机给它发消息，让它在实验机上整理文件、处理桌面任务。 在当时，那个瞬间确实很有未来感。 人在海滩上打扑克，电脑在城市的另一边，AI 在那里默默操作文件。以前说“AI 使用电脑”总觉得像 demo，直到我真的在手机上发一句话，回头看到实验机上的任务做完了，才觉得这东西离现实不远。 但也是那一周，我开始对 OpenClaw 这类桌面智能体冷静下来。 它方向很有前景，但问题也暴露得很清楚：权限怎么给？成本怎么控？它凭什么碰我的文件、浏览器、账号、密钥？出了错谁负责？一个普通用户到底应该把多少电脑交给它？ 当时我写 OpenClaw 的结论，大概是：它不是答案，但它让答案变得可见。 结果兜兜转转几个月之后才发现，这个“答案”不是我追着看的各种小龙虾换壳版，而是曾经藏在 ChatGPT 侧边栏里很不起眼的 Codex。 更准确地说，是最近几个月更新之后的 Codex App。 Codex 一开始压根儿不是干这个的 Codex 并不是新东西。 2025 年 5 月，OpenAI 发布 Codex，当时官方描述是一个 cloud-based software engineering agent。它可以在 ChatGPT 侧边栏里接收编码任务，跑在独立云沙箱里，读写代码文件，运行测试、linter、type checker，然后把结果提交给你审查。 那时候我对它的感受差不多是：“哦，ChatGPT 里面多了个能帮忙改代码的远程工位，不过我写代码有 cursor 啊，用不着这个。”那时日子就这么惬意，除了新模型好像就没什么能在科技圈掀起波澜的。 能让我感到兴奋的是 25 年底横空出世的 OpenClaw 这样更刺激的东西：能操作桌面，能接聊天平台，能像一个系统用户一样去完成任务。虽然粗糙，但有一种很强的冲击力。 所以后来我追 OpenClaw，追腾讯的 WorkBuddy/QClaw，甚至研究豆包手机、Galaxy AI、AppFunctions 这些路线时，也完全没有把 Codex 当成同一张桌子上的玩家。不过倒是用上了 Codex：此时大家都开始脱离 IDE 使用 Claude Code 这样的命令行 AI 工具来写代码，而我那时也想赶潮流，却还不太会用命令行，既有 CLI 端又有桌面端 App 的 Codex 便被我作为 Claude Code 的替代品。 ...

    免费养龙虾？腾讯这招有点狠

    3月6日，鹅厂门口现场给排队的近千人免费“养龙虾”。来自腾讯云 Lighthouse 的工程师为用户免费安装调试 OpenClaw，部署到获取了免费试用期限的腾讯云电脑上，接入腾讯混元提供免费试用额度的 DeepSeek、元宝等模型，直接开始体验“养虾生活”。 我觉得这是一次相当有趣的尝试，对比其他云服务厂商的“高傲姿态”——较高付费门槛，走不完“最后一公里”的部署流程，缺少技术支持，离非技术背景的用户其实很遥远。腾讯则帮用户实现一步到位的部署，用大家都熟悉的 QQ 来作为交互渠道，让来凑热闹的大爷大妈也能轻松认领走一只能收发邮件、写文档做ppt、编程……最重要的是能直接投入工作的“小龙虾”。让更多空有兴趣但不知到该怎么入局的群众来成为用户，无论能否成功转化，我认为这都是相当精明的。 然而，正如我之前所讲的，我认为 OpenClaw 还是不够适合普通用户。即便是经过工程师们悉心育幼，小龙虾也不一定会成长成乖宝宝。安全隐患被隔离到了云电脑中，是个明智的设计，但用户仍然可以被指导着把密码、密钥等关键信息提供给智能体，暴漏在外，风险依然存在；初期费用为0，但试用期限过去后云电脑的费用和无法预知的高 token 消耗仍然会让用户寻思“这到底值不值”；有画图、生成视频等需要的用户会发现还是那些专业工具质量和性价比更高，只是为了写写文章、聊聊天的会意识到小龙虾并不比豆包方便。全民养龙虾目前还只能是个概念，需要解决的问题还很多。 腾讯此举的意义是，他们将人们对 OpenClaw 的热情推向了更高峰，提供更“亲民”的服务，打响了名声，从边缘再次坐回牌桌。就好像去年及时接下 DeepSeek 的热度让元宝用户用上“满血版 DeepSeek”一样。 对了，到底为什么已经不算啥新玩意的 OpenClaw 现在还能在国内掀起这么大风浪啊，也是挺诡异。 这也是我应当学习思考的，挖金子不容易，不如想想怎么卖铲子，但不是有什么新东西就去照搬，而应该去从用户的角度思考有什么简单的改进可以做，做出差异性来。 半个月前，倒腾着阿里的无影云“一键部署 OpenClaw”时，我就在想能不能把这个流程简化、自动化，来直接卖真正上来就能工作的产品给用户，但我当时太在意安全性、隐私性等问题，想偏了方向，最后得出“技术上难实现”的结论，如果我当时愿意放低眼光，去试着做出这个真正意义上的一键部署，说不定就……被腾讯这波创死了吧。但总归是值得反思的。
