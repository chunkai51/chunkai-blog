    究竟该干嘛？

    March 13, 2026

    我有一点沮丧，明明提前了将近一个月接触到 OpenClaw，但由于谨慎或者说是懒，除了写一点垃圾文章以外没有做任何“布局”，以至于没挣着一点儿东西，还不如上闲鱼给人500元包安装包卸载去。

    当然老想着搞钱也很无聊，机会很多，能看懂形势找到下一步该怎么做更重要，而我，目前看不出来啥。

    听说 Meta 收购了那个 moltbook，这是什么意思，那玩意有什么价值吗，考虑到他们之前还炒元宇宙，我觉得不咋靠谱。但至少 Agent 肯定还是大家都在探索的方向，Meta 作为搞社交平台的，这次收购的目的可能也是要研究 Agent 的交流、协作模式吧。

    我呢，目前刚刚勉强搞明白 ReAct、agent、skill、mcp、swe-agent、harness 这些黑话都是什么意思，稍微熟悉了一下 python 语言。学 Agent 最麻烦的是没资源，那些个论文读着似懂非懂，lectures 也听得似懂非懂，问 AI 就让我去做什么 SDK，还要翻 OpenAI、Anthropic的开发者文档……实在不像 Java 那样的成熟体系好学。

    至少经过了这两周的东学学西看看，我大概能提炼出接下来的长期安排：

    • 从理论角度学 Agent（听 lectures，学论文，从较高视角理解 Agent）
    • 利用 AI 工具加速学会完整的 Java 后端开发体系（明白后端是在干嘛）
    • 学好数据库和软件工程（明白软件工程师是在干嘛）
    • 复现/开发 Agent 项目（丰富简历）
    • 开始刷题（复习数据结构与算法，避免大脑生锈）

    之前的 Agent 学习计划其实可以继续，但基础的软件工程/后端体系一定要学。因为 AI 更新太快，必须要有点根基，才能实现真正的利用 AI 干中学，不然就是被 AI 牵着走，可替代性太高了。可以继续关注技术新闻，写点东西，甚至做点其他产出，找找机会，但不要轻易误了正事。
