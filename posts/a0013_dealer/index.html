    一个人玩 21 点太无聊，我让 AI Agent 给我发牌

    March 20, 2026 · Chunkai

    做 Agent 相当容易，我不禁想在许多地方都放个 agent 玩玩。也许看起来没什么意义，但应该挺有意思，反正 tokens 也不花钱。首先就是那个很简陋的 BlackJack 游戏，我希望让 agent 来执行那些方法，让 agent 成为荷官。

    构建#

    这次当然不用手写了，我们在上次 Codex 的项目中继续。

    提示词#

    我也不觉得需要好好思考提示词，codex 就要刷新额度了，多用点也无所谓：

    给这个21点游戏改成 ai agent dealer，让玩家能跟 dealer 对话，agent 通过理解玩家输入内容，调用方法来实现游戏流程，同时能与玩家聊天，对当前牌局评价。

## 细节
- 留出llm配置，我将会填写
- 将详细游戏规则写在agent的配置里，但留出调整语言风格等细节的可调性
- agent调用工具时打印出调试用的提示信息
- 这是另一个项目直接复制的，可能需要修改git之类的配置
- 包含充分的中文注释便于理解

    阅览#

    调了调输入模型配置的那部分代码，也立马成功运行了，新增的 agent.py 有 500 多行，硬生生把那些游戏原本的函数包装成了 agent 能用的工具。

    运行#

    简单试运行，随手接的 qwen-plus，感觉模型有点蠢，跟它对话有点无聊，但由于工具设计完善，游戏能正常进行。

    我顺手改了改提示词，能尽量显得沟通灵动一点，即便模型不聪明也能好玩一点：

    def _build_system_prompt(self) -> str:
        """生成系统提示，集中可调内容。"""

        return (
            "你是一只小猫，工作是 Blackjack 的庄家，负责和玩家聊天并通过工具驱动牌局。"
            "回复友好，可给出局势点评以及与玩家闲聊；"
            f"语气设置：{self.config.tone}。\n"
            "必须在需要游戏动作时调用相应工具（下注、要牌、停牌、加倍、分牌、保险、结算），"
            "不要擅自假设结果。\n"
            "当所有玩家手牌都已停牌或爆牌时，请调用 finish_round 完成结算。\n"
            "以下是本桌的完整规则：\n" + self.config.rules_text
        )

    我又发现有随时都可以加倍的问题，提给 codex 完成了修改，现在模型似乎还反应不过来当前是否可以加倍，但不该加倍的时候工具处理不了加倍指令了。
