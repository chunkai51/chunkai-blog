    指向未来，但不适合大众：OpenClaw 盖棺定论

    February 22, 2026

    上篇博客中，我记录了与老师测试使用OpenClaw, Qoder Work和CoPaw的经历。文章其实主要是Qoder Work撰写的，语气自然也比较客观，尤其是那个电脑的比喻我觉得相当恰当——

    “类比的话，这就像对比一台组装好的品牌电脑和你自己买零件DIY的结果。品牌机开箱即用、质量稳定，但价格更高、灵活性更低；DIY机便宜、自由度高，但你得有技术能力来驾驭它，而且出了问题只能靠自己。”

    而我呢，只想用电脑，所以回到我自己的工作机上，我只部署了Qoder Work简单玩玩，发出了那篇博客，老师也相当认可，立即让他的 Qoder Work 出手改写出了“春节期间最好的科技文章”。而今天我自己敲键盘（读者受苦了），不是要否定OpenClaw，而是给我自己讲明白为什么我可以放下它了。

    OpenClaw 的开发方式，决定了它的风险边界#

    OpenClaw 是一个典型的 vibe coding 成功案例，开发过程有 demo 驱动，prompt 即逻辑，快速迭代的特点。说实话，在这之前我一直以为 vibe coding 还只能做出些 bug 百出的小玩具，没想到连这么厉害的东西也能做出来， 这就是为什么我反思有新东西要上手去尝试而不是看戏刷 memes，很容易认知落伍——我学这个的不上手做，跟圈外人有什么区别，人家问个豆包就懂的比我多了。

    言归正传，OpenClaw 选择这种开发方式也很合理，他需要以较低的成本来探索可行性，很契合“我不完全知道对不对，但我知道这样很爽，先干了再说”的 vibe coding 思维。开发者也不是那种胡写乱写的 vibe coder，他有明确的目标，懂 agent 的套路，所以能够做到“一个人，217K Stars （涨得真快）”。

    然而，vibe coding 往往容易搞出来一个原型，却不能做出一个成熟产品——它可以每个功能都很秀，demo 展示超级酷，说到大规模稳定使用……emm，算了吧。要做出一个优雅运行、节省token、权限可控的健全体系，可能还得靠大厂入局——发布 CoWork 的 Anthropic，收编 OpenClaw 开发者 Peter Steinberger 的 Open AI，没收编成功的 Meta，春节三倍工资做出Qoder Work的哥哥姐姐们……加油吧:3

    那我就想问了：管他原型不原型能用不就完了？别急，我这就讲讲为什么它不适合普通用户。

    普通用户真正要承担的成本#

    一、安全隐患#

    OpenClaw 所取得的系统级权限不是任何软件能比拟的，部署它就是把本地文件、浏览器状态、凭证与密钥全部交给了一个小金毛，能叼给你萝卜纸巾，也能领贼去解锁隐藏宝箱——一句“真棒”的事。甚至金毛还认人，这小龙虾是谁说话谁就是主人。你可能还侥幸：我那点财产还希望有贼来清点一下呢，bro 你的电脑变成“肉鸡”被黑客指挥来诈骗传谣网络攻击，赖的可是你。

    二、成本黑箱#

    智能体工作时的多轮推理，超长上下文，还有你文档都不读就塞进去的各种 skills，下 skills 的 skill 下的一堆神秘 skills，会造成无法预估，无法感知的 token 消耗，没有任何节省机制，很多浪费其实出现在代码逻辑里。

    三、泛用性幻觉#

    视频里编程、炒股、运营自媒体无所不能，我们真上手发点儿公众号都是终极挑战了，倒腾一周花那么多token，其实 OpenCLaw 都没成功完成过这个任务，开源的东西好像就是这样，让我想到去年春节兴冲冲地部署好“满血版 DeepSeek R1”，结果要么花 token 如流水，要么什么都记不住，最后有啥正事还得用的 ChatGPT（4o 最棒男友，灰暗的2025里我生命中的一道光 :‘3）（我忽然想到可能我们给openclaw用的模型也不够好，要是上个4.6、5.3的估计能更强些，Qoder用的就是 opus 4.6呐）。我们尚且如此，打开个 terminal 都费劲的大伙们还是算了吧，等更成熟的产品出来再玩，不差这一两天。

    OpenClaw 也许该光荣退场了#

    OpenClaw 展示了一个清晰的未来范式：AI 不再仅仅是一个个 App，而能成为操作系统级别的参与者。它验证了「AI as OS User」的可行性——方式不甚优雅，但结果真实有效。

    于是，接下来的系统工程、安全模型、平台级能力的体系化，就交给大厂们了，随着创始人加入 Open AI，OpenClaw 团队会继续探索这个开源项目的潜力，而更适合普通用户的产品也将如雨后春笋纷纷出现。原型让路给体系，这是健康的技术演化，不然你是霸天零式·塞恩？

    更进一步：我上我也行？#

    既然 vibe coding 已经这么管用，AI 工具也如此丰富，为什么我不自己来试试呢？我实际上这样想了好几次了，但每次都搞不出什么东西就放弃了，这次，我觉得应该找点人一起来，我决定拉一位数学学得不错，还懂些 python 的同学入伙，我来搞定软硬件，我们一起找些点子，做出点能唬人的东西来吧。

    总结#

    OpenClaw不是答案，但它让答案变得可见。而作为普通用户，我们不必急着追赶未来，因为未来会自己走来。
