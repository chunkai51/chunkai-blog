    OpenAI Agent SDK 学习笔记

    March 24, 2026 · Chunkai

    比起其他让人头疼的 OpenAI Developers API Docs，OpenAI Agent SDK 算是比读起来稍微轻松些的，甚至有简体中文。我决定读一读这些内容，虽然这像是词典一样的工具，读起来可能比较枯燥没有逻辑，但我作为一个“不识字”的人，读什么都是学。我将在这里以我自己舒服的方式记录一些我认为重要的内容以及思路梳理。

    智能体概览#

    An agent is a large language model (LLM) configured with instructions, tools, and optional runtime behavior such as handoffs, guardrails, and structured outputs.

    基础配置#

    示例：#

    from agents import Agent, ModelSettings, function_tool

@function_tool
def get_weather(city: str) -> str:
    """returns weather info for the specified city."""
    return f"The weather in {city} is sunny"

agent = Agent(
    name="Haiku agent",
    instructions="Always respond in haiku form",
    model="gpt-5-nano",
    tools=[get_weather],
)

    必需属性#

    • name 智能体名
    • instructions 系统

    一些我注意到的东西#

    • 动态 instructions: 创建智能体时需提供 instructions，但也可以通过返回提示词的函数动态提供 instructions
    • 强制工具使用：配置 tool_choice 选项
    • 工具使用行为：调整 Agent 的 tool_use_behavior 参数来确定工具使用后 LLM 处理结果还是直接停止（在之前我自己构建的简陋 Agent 看来都是工具使用后直接停止的）

    模型#

    本篇介绍调用 OpenAI 模型和非 OpenAI 模型的方法，没有看到什么值得记录的内容，需要时查阅就好。

    工具#

    工具让智能体能够行动。

    OpenAI SDK 支持的 5 种工具调用方式：

    • 与模型一起在 OpenAI 上运行的官方托管工具
      • 使用 OpenAI 提供的模型时能用一些内置工具
      • 涵盖搜索网络、用沙箱运行代码、生成图像、MCP服务等功能
    • 在本地/runtime 环境中运行的工具
    • Function Calling：封装 Python 函数作为工具
      • SDK 会自动通过函数名、docstring、参数表等来完成工具设置，部分配置也可自定义
      • 文档上讲如果不想将 python 函数作为工具，也可以自定义工具调用，这个部分的示例代码很像我之前写的 agent，但我还不太明白——这不就是 python 函数吗，也许是另外包装了一层？
    • 将另一个 Agent 作为工具
    • 调 Codex 任务作为工具
