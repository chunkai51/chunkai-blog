    有团队了？接下来呢？

    March 2, 2026

    我显然对搞钱过于着急了，不是随便一个人订阅各种 AI 工具纯靠动嘴就能做出一个能挣钱的创业项目的。我需要先学些东西，至少要能看懂 AI 写的代码，能构建起一个 Agent 的框架，才能不烧一堆 token 做出没什么意义的屎山代码。

    我的伙伴数学底子很好，也有学 python，但事实上我们都还有很长的路要走，而且时间有限。目前的目标是——在六月前搞出有脸写在简历上的 Agent 项目。

    那么，我们在三月就应当学完所有的基础知识，包括 Python 和 LLM、Agent 的基础，目标是自己糊出一个 agent 来。

    翻翻日历，我们有四周时间，可以做一个大概完不成但是做着挺好玩的计划：

    第一周（2/3-8/3）：Python 学到够用#

    我有 Java 经验（算得上的话），伙伴 Python 在学面向对象，我们可以算是同一起跑线。Python 这玩意应该没多难，我只需要尽快熟悉语法和特性上与 Java 的异同就可以掌握，再学些 pytorch 的基础部分，能读懂代码就好。要鼓励伙伴快点学，多去读文档，做点小玩具，在实践中增强理解加速学习。

    我的具体规划

    • 周二学列表/dict
    • 周三学函数式写法
    • 周四学类与面向对象特性
    • 周五学装饰器、async/await
    • 周末选一个较综合的 Java 项目用 python 重写
    >这规划可能是AI胡写的，感觉完全要不了这么慢，今天周三，我学完了面向对象特性，我昨天甚至去打LOL了
>今天周四，后面的有点抽象了，我在学异步
>还在周四，我感觉差不多了，剩下的知识可以边用边补了
>我想学一下现在的AI编程是个什么流程，尝试用Codex或Qoder做一个python的21点游戏。不能忘了我学这不是为了自己做，能看懂AI做就好了

    第二周（9/3-15/3）：学习 LLM+Agent 基础#

    说实话，我们完全不知道 Agent 到底是啥，该怎么学，根据之前听某个网红的说法，我打算边读姚顺雨关于 Agent 的论文，边上UC Berkeley 的 CS294-196，那就是一天 2-3 个 lecture，抽空再把论文一读。

    别忘了参考 ChatGPT 给的指导：

    重点学： Prompt engineering Chain-of-thought ReAct Tool use Function calling JSON schema 输出控制 要亲手做： 一个带工具的 agent: 计算器/网络搜索/文件读写 一个多步任务 agent: 任务拆分 中间状态保存

    >今天是周一，我玩了一天 MacBook，大概部署好了软硬件，我觉得这种便携性和续航能力真的能让我的学习效率有很大提升
>还是周一，我借助知乎大佬的解读和AI读完了姚顺雨关于 ReAct 的论文，正在读关于 SWE-Agent 的论文
>现在周二，我听了半个 lecture
>我搜集信息对比了市面上几乎所有主流的 Coding agents 使用方案，最后还是决定充个 Plus 用 OpenAI Codex，相信贵有贵的道理，可拓展性也强，似乎还能偷接给OpenClaw用
>也许我也会续一个月 Qoder Pro 来完成交接并且对比性能，大概也会买些国内模型API，反正不会浪费
>没错我上周末说的 BlackJack 还在选工具的阶段，而且现在买 Plus 订阅的渠道还是个问题，先把知识学够吧
>今天周三，学校的事好忙，我几乎没有进展
>今天周四，我开始做那个 Python 项目了，我觉得 Agent 学习可能还得慢慢来
>周五，VS Code出了点问题调了半天，还在跟MacBook磨合
>周六休息一下，不过我忽然意识到好像进度不够欸，当然这些计划也就是参考，在进行就好
>周日休息

    第三周（16/3-22/3）：学习 Agent 架构#

    我们实际上已经部分脱离了这个计划。伙伴还在学 python，大概比起我天花乱坠的幻想还是精进技术更可靠。我还没完全搞明白 agent 该怎么学，去问某网红还没得到回复，问教授也似乎得不到什么有价值的回答，b站上都是些卖课卖项目的，油管也差不多，问 AI 回答都好官方不确定能不能采用，倒是在 Hacker News 上刷到过几篇写得还不错的博客 （比论文读起来舒服多了），虽然还是没下到具体学习内容的层面，但也让我纠正了一些大方向上的认识。

    那么，这周也就是按 AI 讲的来做好了，不要一直袖手旁观心想“这些东西都好高大上我肯定学不会”，要去做，随便调个llm，写个 agent loop，哪怕就是实现一个计算器什么的，先体会一下到底是干嘛的，另外理论学习也不能停，那么多水课就应该用来听 lectures 读课件、论文。

    >今天周一，我看了很多篇 blog，东西没学多少，倒发现跟他们的比起来我的博客好 piǎ 气，
    于是让 codex 帮我给 blog 换了字体成了 JetBrainsMono + 无衬线，还算好看，但还差一些感觉，以后再改吧，
    懒得下 hugo 直接在 pages 看结果，测试一次两个 contribution，github 直接绿成教室窗帘了
>还是周一，我决定手写一个 agent loop 感受一下，搞定了结构和理论认识
>周二被学校的各种破事搞到疯，十点多出了学院楼一路跑到操场跑了三四公里，感觉好多了，倒头就睡
>今天周三，我把 agent loop 写好了，挺有意思，其实没多难，早该做了
>那个网红回复我了，让我看他其他视频，去他的吧，倒是还有个热心网友回复我，也是讲先学一门后端，再去复现 agent 项目，挺有道理，
    我还问了一个看起来少见的还跟技术前沿比较接近的老师怎么学 agent，他让我最好去报课来学，还要学好 python，好吧，也值得考量
>今天周四，我好像还在纠结学习路线的事，事实上也许是又开始逃避行动了，
    我倒是看完了两个 Lectures，接下来几天应该会坚持把剩下的继续看，同时做着笔记
>我觉得还是不应该放弃做东西的想法，既然已经体会到了做一个 agent 有多简单，应该多留意有没有需要解决的问题，
    哪怕是为了做东西来玩，也应该去做，很多有意义的事情都是从漫无目的玩起步的吧
>周五，我开始阅读 OpenAI Developers 文档，lectures 还在看，另外顺手给 21 点加了个 agent dealer，还挺好玩
>今天周六，周末真的应该休息吗，看着时间过去的感觉不太好，但我没有做什么事情的想法，
    有时我害怕，不敢停下来，我怕我会再次以为自己“清醒”了，把这些事当作另一个 side project 放弃掉，
    不过回过头来看我可没有落后进度一点儿呢，第四周是一大周，这个周末就搞好后勤工作，准备圆满结束三月吧

    第四周（23/3-31/3）：做一个完整 Agent 项目#

    如果我不够掌握基础，也做不出好的项目。继续读文档，尽快确定究竟怎么以高效率的方式补上缺失的技术.

    >今天周一，我读了 OpenAI 的 Prompt Engineering 文档，说实话没太懂，
    还听了个 lecture，关于 agentic model 后训练的，也是云里雾里
>今天周二，我读了读 OpenAI Agent SDK
>周三，我写学校作业去了……
>到现在，有意思的工作似乎都结束了—— Blog 建好了，新电脑玩开心了，简陋的 agent 糊出来了，小玩具做了一点——
    真正到了沉淀技术的时候，我想是相当枯燥的。我也十分争气地回到了早上起不来，晚上不早睡，天天没产出，感冒、眼干，还总想抿两口的状态。
    这种瓶颈期如何度过，会决定我的规划是真的有意义还是另一个笑话。
>那么，需要分析一下是什么在限制我
    1. 没有明确的方向，做出第一个 agent loop 相当于导论课结课了，但面对浩荡的知识体系，我仍然缺少认识，所做的事情总怀疑有没有用
    噢，好像就是这一点，这就是唯一的问题。
    不满我说，我已经基本清晰如何成为一个称职的 agent 工程师，问题其实在于我该如何在这一两个月内达到那个程度。

    千思万绪，只汇成了三个字——干中学

    >周四，眼睛是在不适没有做什么事情，也没休息好
>周五，读文档
>周六，把 ChatGPT 升级到了 Plus，来玩点真格的吧
>周日，休息，玩 ChatGPT，配置软件
>周一，上课、写作业，读文档
    我需要开始偏系统化地继续学习 python 和前端的技术栈，迅速掌握语法和编程思想，过渡到做大型项目的阶段
    我需要多回头看看一段时间的工作有没有实际意义，避免钻牛角尖
>周二，倒腾了一天电脑，优化学习环境
>周三，首先是糊弄学校任务，
    我发现 Codex 做这些小任务真是无敌了，工程一建，课件一发，自己就吭哧吭哧干活去了，
    需要协商/授权就会发通知，遇到什么问题都会自己想解决方案，最后写好连带着解决问题过程的实验报告
>然后刷 HN，发现了个有意思的主题，尝试用 Codex 来发了一篇微信公众号文章来讨论，效果还挺不错

    最后三月还是不明不白地结束了，并没有完全执行完计划，但我很欣慰我真的半装模作样半认真地进行下来了，而且我做到的事情已经很令我满意了。麻烦的学校事务处理得差不多了，我在舒适的春景里沉思着度过清明。

    我已经搞懂了需要学什么，找到了合理的学习方法，将学习工具调整到了最佳状态，甚至已经把需要看的课程、读的文档、做的项目都放在了手边。四月，我只需要像当时学 Java 一样把这些东西学完——这还是我相当有信心做到的事情。
